    Connexion GitHub

    Pour publier directement depuis cette page, il faut une seule fois créer un « jeton d'accès » GitHub (5 minutes).

    Sans jeton, vous pouvez quand même tout préparer ici puis télécharger les fichiers.

    Comment ça marche

    1. Remplissez la fiche, section par section. La colonne « Vérification » signale ce qui manque.
    2. Votre travail est gardé automatiquement sur cet ordinateur (brouillon) : rien n'est perdu si vous fermez la page.
    3. Rien n'est publié tant que vous n'avez pas cliqué sur « Enregistrer sur GitHub ».
    4. Le site se met à jour 1 à 2 minutes après l'enregistrement.

    Connexion GitHub

    La page enregistre les fiches dans le dépôt GitHub du site, au nom de votre compte, grâce à un jeton d'accès personnel. Le jeton reste dans ce navigateur : il n'est envoyé qu'à GitHub.

    Réglages du dépôt (à ne pas modifier)
    Comment créer un jeton ? (une seule fois, 5 minutes)
    1. Connectez-vous sur github.com avec votre compte (celui qui a accès au dépôt kmcfrance.github.io).
    2. En haut à droite, cliquez sur votre photo → Settings → tout en bas à gauche Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    3. Token name : par exemple « Préparer événements — ordinateur du bureau ».
    4. Resource owner : choisissez kmcfrance.
    5. Expiration : par exemple 1 an (366 jours). Notez la date : il faudra en recréer un ensuite.
    6. Repository access : Only select repositories → choisissez kmcfrance.github.io (et rien d'autre).
    7. Permissions → Repository permissions → Contents : Read and write. Ne touchez à rien d'autre (« Metadata : Read-only » s'ajoute tout seul).
    8. Cliquez sur Generate token, puis copiez le jeton (il commence par github_pat_) : GitHub ne le montre qu'une fois.
    9. Collez-le ci-dessus, puis cliquez sur Tester la connexion.

    Si « kmcfrance » n'apparaît pas dans « Resource owner », ou si l'organisation doit approuver le jeton, demandez à la DSI (dsi@kadampafrance.org). Solution de secours, moins sûre : Tokens (classic) → Generate new token (classic), cocher seulement public_repo.

    Ce jeton donne le droit de modifier le site. Ne le partagez jamais (ni par e-mail, ni dans une fiche, ni dans un message). Ne cochez pas « Se souvenir » sur un ordinateur partagé.

    Jeton perdu ou ordinateur volé ? Supprimez-le tout de suite sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens → le jeton → Delete.
